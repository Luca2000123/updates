# Note legali

Questo repository **non è un prodotto pubblico**. È l'infrastruttura di
distribuzione per applicazioni **personali**, usate esclusivamente dal
proprietario sui propri dispositivi.

È pubblico per un motivo tecnico, non perché sia pensato per essere scaricato
o usato da altri: l'API di GitHub, se non autenticata, impone un limite di
richieste per indirizzo IP, e solo un repo pubblico permette ai client delle
app di leggere i manifest di aggiornamento come file statici senza incapparci
(vedi README). Non è un invito all'uso, alla distribuzione o al supporto per
terzi.

## Cosa c'è qui, cosa no

- **Qui**: solo i binari compilati allegati alle Release e i manifest di
  aggiornamento generati automaticamente da essi.
- **Non qui**: nessun codice sorgente delle app. I repository sorgente sono
  privati e non collegati pubblicamente a questo.

Tutto quello che viene distribuito da questo repository è fornito "così com'è"

componente — binari, manifest, l'intero servizio — può cambiare, essere
rimosso o interrotto senza preavviso.
